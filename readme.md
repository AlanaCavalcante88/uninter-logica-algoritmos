# 📚 Lógica de Programação e Algoritmos com Python

Repositório dedicado ao armazenamento de exercícios, desafios práticos e trabalhos desenvolvidos durante a disciplina de **Lógica de Programação e Algoritmos**.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python 3.x
- **Ambiente/Editor:** VS Code
- **Controle de Versão:** Git & GitHub

---

## 📂 Estrutura do Repositório

O conteúdo está organizado por módulos/tópicos abordados ao longo do trimestre:

- `01-introdução-à-lógica-e-algoritmos` - Introdução, tutorial do Pycharm e Google Colab
- `02-variaveis-e-expressoes/` — Tipos de dados, operações aritméticas e entrada/saída de dados (`input`/`print`).
- `03-estruturas-condicionais/` — Controle de fluxo com `if`, `elif`, `else` e operadores lógicos.
- `04-estruturas-de-repeticao/` — Laços `while` e `for`, contadores, acumuladores e controle de fluxo (`break`/`continue`).
- `05-funcoes-e-modularizacao/` — Criação de funções (`def`), parâmetros, retornos e escopo.
- `06-estruturas-de-dados/` — Listas, tuplas, dicionários e conjuntos.
- `trabalhos/` — Projetos e trabalhos avaliativos da disciplina.
